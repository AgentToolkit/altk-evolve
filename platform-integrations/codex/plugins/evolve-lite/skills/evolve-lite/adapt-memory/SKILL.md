# Adapt Memory

This skill mirrors a just-saved native memory into the shared evolve store. It
is specific to hosts with native self-directed memory and is a no-op on this
platform — there is no native memory store to mirror from.
To capture a reusable lesson here, follow the "Save" section of the Evolve
instructions (EVOLVE.md) this plugin installs, which writes the entity into the
evolve store directly.
